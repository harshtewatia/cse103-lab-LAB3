# Markdown Syntax Guide

This guide demonstrates common Markdown syntax used in this repository.

## Headings

# Heading 1 (largest)
## Heading 2
### Heading 3

## Text formatting

**Bold text**  
*Italic text*  
~~Strikethrough~~

## Lists

Unordered list:
- Item A
- Item B
  - Nested item B1 (indent with two spaces)

Ordered list:
1. First step
2. Second step

## Code

Inline code: `print("Hello")`

Fenced code block with Python syntax highlighting:

```python
def greet(name):
    return f"Hello, {name}!"
```

## Hyperlink

[GitHub](https://github.com)
